# Student Registration Form

A clean, structured, and responsive Student Registration Form designed with custom HTML5 and CSS3 styling.

## 📌 Features
- **Form Fields:** Covers student details like Roll Number, Name, Father's Name, DOB, Mobile Number, Email, Password, Gender, Department, Course, Photo upload, City, and Address.
- **Custom Design:** Built using CSS table-based layout alignment with custom styling for radio buttons, checkboxes, and select dropdowns.
- **Responsive & Centered:** Centered interface with clean padding, soft color tones, and custom background shadow.

## 🛠️ Tech Stack
- **HTML5**
- **CSS3**
